PRETTY PAW
HTML5 / SCSS / JavaScript / Webpack / БЭМ

Зоосад «PrettyPaw»

Многостраничный сайт зоосада: главная и страница с разделами «О зоосаде», «История», «Добрые дела» и «Карьера». Адаптивная верстка под мобильные, планшет и десктоп, видеофон, слайдеры и анимации на GSAP. Сборка на Webpack, стили на SCSS с БЭМ-именованием.

  • Сборка: Webpack 5 (режимы dev и prod, dev-сервер), Babel, PostCSS (postcss-preset-env), CSS отдельным файлом, объединение media-запросов, генерация фавиконок, две HTML-страницы через HtmlWebpackPlugin; в prod-сборке изображения сжимаются (mozjpeg, pngquant).
  • Изображения и деплой: WebP создаётся отдельным скриптом на imagemin-webp (npm run webp), публикация на GitHub Pages командой npm run deploy (gh-pages).
  • Верстка: семантический HTML5, БЭМ, SCSS с партиалами через @use, переменные и миксины для брейкпоинтов (mobile-first), Flexbox и CSS Grid (grid-template-areas в блоках «О зоосаде», «Карьера» и футере).
  • Адаптив: брейкпоинты 576 / 768 / 1024 / 1240 / 1600 px (min-width), <picture> с WebP и JPG для четырёх диапазонов ширины экрана, lazy-loading изображений на главной странице.
  • Интерактив: слайдеры на Swiper (автопрокрутка каждые 3,5 с, пагинация, цикл); мобильное меню до 1240 px на GSAP-таймлайне — пункты выезжают с боков; от 1024 px при наведении на карточки локаций GSAP раскрывает описание и плавно меняет фон с предзагрузкой изображений.
  • Навигация: разделы второй страницы переключаются по хэшу в адресной строке на JS (hashchange) без перезагрузки; без хэша открывается первая секция; активный пункт подсвечивается в обоих меню.
  • Детали: видеофон с источниками WebM и MP4, кнопка «наверх» появляется после половины экрана, адаптивное поведение через matchMedia, JS разбит на ES-модули (sliders, menuControl, locationHover, pageControl и др.).

  • SCSS
  • JavaScript
  • Webpack
  • БЭМ

Парк-отель на Онежском озере

Одностраничный сайт загородного парк-отеля на Онежском озере: о нас, развлечения, три типа апартаментов с ценами и форма бронирования. Адаптивная верстка на Flexbox и CSS Grid, форма с проверкой на JavaScript и демо-отправкой (без бэкенда).

  • Разметка: семантический HTML5 (header, nav, main, section, article, footer), форма с label, fieldset и legend, статус отправки с aria-live.
  • Стили: CSS-переменные для цветов, clamp() для шрифтов и отступов, CSS Grid для карточек (3 колонки → 1), Flexbox для навигации.
  • Адаптив: брейкпоинты 1440 / 1024 / 768 / 508 px, отдельные фоны первого экрана под каждую ширину, меню в колонку на узких экранах.
  • Форма бронирования: email, имя, даты заезда и выезда, тип апартаментов; novalidate и собственная проверка на JS с понятными сообщениями об ошибках и успехе.
  • JavaScript (ES6+): дата заезда не раньше сегодняшней, выезд позже заезда; FormData, async/await и try/catch/finally для демо-отправки, блокировка кнопки на время отправки, локальная дата без сдвига часового пояса.
  • Детали: иконки Font Awesome, бейдж VIP через ::before, плашка с ценой поверх фото, кнопка «наверх», появляющаяся при прокрутке, width и height у изображений против сдвигов макета.
  • Доступность: aria-label у навигации и иконок, :focus-visible, prefers-reduced-motion.

KUGOO — запись на тест-драйв электросамокатов

Лендинг магазина электросамокатов: каталог моделей, запись на тест-драйв, корзина, избранное и сравнение. Адаптивная верстка для телефона, планшета и десктопа. Вся интерактивность написана на чистом JavaScript — без библиотек и бэкенда (данные корзины хранятся в браузере).

  • Магазин на JS: корзина, избранное и сравнение с сохранением в localStorage, живой поиск по каталогу, оформление заказа.

Aliance Production — корпоративный сайт производителя химии

Многостраничный корпоративный сайт компании по контрактному производству бытовой и автомобильной химии, косметики и аэрозолей, с собственными торговыми марками и блогом. Серверная часть на PHP: шаблоны и обработчик заявок с отправкой в Telegram. Адаптивная верстка, слайдеры на Swiper. Тексты и логотипы клиентов — заглушки.

  • Структура: 10 страниц (главная, о компании, контрактное производство, страница продукции, торговые марки, страница бренда, блог, статья, контакты, политика конфиденциальности) и страница 404.
  • PHP-шаблоны: общие header-page.php и footer.php и 16 блоков в template-parts (хлебные крошки, шаги, карточки, слайдеры, блог и др.); страницы собираются из блоков и настраиваются переменными — заголовок, стиль шапки, списки.
  • Заявки: две формы (секция «Хотите сотрудничать?» и модальное окно), проверка в Just-Validate, отправка через fetch на handler.php, который передаёт заявку в Telegram-бот менеджера; окно «Спасибо за заявку».
  • JavaScript без фреймворков: 4 слайдера на Swiper с брейкпоинтами, мобильное меню, шапка меняет высоту и тему при прокрутке, модальные окна (Esc и клик по фону), маска телефона +7 (XXX) XXX-XX-XX.

  • Оформление: три варианта шапки (светлая, тёмная, с фоновым изображением) выбираются переменной $header_style, логотип в светлой и тёмной версиях.
